skew heap merge

Follow the smaller roots down the right paths, then swap children as the recursive calls return.

A/B identify the original heaps. L/R mark child edges. Orange marks the current operation, green marks visited merge roots, and dashed rings mark roots waiting for a recursive result.

Merge pseudocode 
SkewedHeapMerge(h, h′)
  if h is empty: return h′
  else if h′ is empty: return h
  if root(h′) ≤ root(h):
    exchange h and h′
  if right(h) is empty:
    right(h) ← h′
  else:
    right(h) ← SkewedHeapMerge(right(h), h′)
    swap left(h) and right(h)
  return h
